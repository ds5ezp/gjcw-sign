LED 전광판 관리 (1층 현관 / 3층 대강당)
==================================================

[구성]
- 업무포털 '전광판 관리' 메뉴 : 콘텐츠 등록·수정·순서·사용/중지, 화면별 미리보기, 전광판 주소 확인
    (통합관리대시보드 Code.gs / Index.html / Style.html 에 들어 있음)
- 전광판 API (이 폴더 API_Code.gs, API_appsscript.json) : 새 앱스 스크립트 프로젝트. 전광판이 목록·이미지를 받아 감
- 표시 페이지 (이 폴더 index.html) : GitHub Pages 에 올림. ViPlex '웹 페이지' 위젯에 등록하는 주소

  전광판(WebView) ──▶ GitHub 표시 페이지 ──(20초마다)──▶ 전광판 API ──▶ '전광판 관리' 시트 / '전광판 이미지' 폴더
                                                                       ▲
                                                업무포털 '전광판 관리' 메뉴에서 등록·수정

[화면]
- lobby : 1층 현관   1152×160, 플레이어 10.10.10.12
- hall  : 3층 대강당 2304×256, 플레이어 10.10.10.11
  (시트 '화면' 탭에서 해상도·IP를 바꿀 수 있음. 접속 키도 이 탭에 있음)

[처음 설치]  viewer@geojecwc.kr 계정으로 진행
1. 업무포털(통합관리대시보드)에 Code.gs / Index.html / Style.html 붙여넣고 새 버전 배포
   → 업무포털 왼쪽 메뉴 '홍보관리 > 전광판 관리' 를 한 번 열면 '전광판 관리' 시트,
     '전광판 이미지' 폴더, 화면별 접속 키가 자동으로 만들어짐
2. '전광판 관리 > 화면·주소' 탭에서 '전광판 API 프로젝트에 넣을 시트 ID' 를 복사
3. 전광판 API 프로젝트 만들기
   - https://script.google.com > 새 프로젝트 > 이름: 전광판 API
   - Code.gs 에 API_Code.gs 내용 붙여넣기 → 위쪽 SHEET_ID 에 2번의 시트 ID 넣기
   - 프로젝트 설정 > 'appsscript.json 매니페스트 파일 표시' 체크 → API_appsscript.json 내용 붙여넣기
   - 함수 testApi 실행 → 권한 승인 (실행 로그에 화면별 콘텐츠 수가 나오면 정상)
   - 배포 > 새 배포 > 웹 앱
       다음 사용자 인증 정보로 실행: 나 (viewer@geojecwc.kr)
       액세스 권한이 있는 사용자: 모든 사용자   ← 전광판은 로그인을 못 하므로 꼭 '모든 사용자'
     → 나오는 웹 앱 URL(…/exec) 복사
   ※ 조직 설정상 '모든 사용자' 가 목록에 없으면 Google Workspace 관리자에게
     '도메인 밖 사용자에게 웹 앱 공유 허용' 을 요청해야 합니다.
4. 표시 페이지 올리기 (GitHub)
   - index.html 위쪽 API_URL 에 3번의 웹 앱 URL 넣기
   - GitHub 에 새 저장소 gjcw-sign 을 만들고 index.html 업로드
     → Settings > Pages > Branch: main / (root) 저장
     → 1~2분 뒤 https://ds5ezp.github.io/gjcw-sign/ 가 열리면 완료
   - 저장소 이름을 다르게 했으면 업무포털 Code.gs 의 LED.PAGE_URL 도 같이 바꿔 주세요.
5. 업무포털 Code.gs 의 LED.API_URL 에 3번 웹 앱 URL 을 넣고 새 버전 배포
   → '화면·주소' 탭의 [연결 확인] 으로 API 가 잘 응답하는지 확인
6. ViPlex Express 에 등록 (아래)

[ViPlex Express 등록]  화면마다 한 번만
1. ViPlex Express 에서 플레이어에 접속 (현관 10.10.10.12 / 대강당 10.10.10.11)
2. 새 솔루션 만들기 → 화면 크기를 전광판 해상도 그대로 (현관 1152×160 / 대강당 2304×256)
3. 위젯에서 '웹 페이지' 추가 → 주소: 업무포털 '화면·주소' 탭의 전광판 주소
     https://ds5ezp.github.io/gjcw-sign/?screen=lobby&key=(현관 키)
     https://ds5ezp.github.io/gjcw-sign/?screen=hall&key=(대강당 키)
4. 위젯 위치 X 0, Y 0 / 크기 = 화면 크기 그대로 (현관 1152×160 / 대강당 2304×256)
   재생 시간은 길게 하거나 반복 재생
5. 게시(전송). 이후 콘텐츠는 업무포털에서만 바꾸면 됩니다 (20~30초 안에 반영)

[주의]
- 전광판 플레이어가 인터넷(ds5ezp.github.io, script.google.com)에 연결되어 있어야 합니다.
  사내망 10.10.10.x 에서 인터넷이 막혀 있으면 표시되지 않습니다.
  확인 방법: ViPlex 에 주소를 등록한 뒤 전광판에 콘텐츠가 나오는지 보기
  (키가 맞는데 계속 검은 화면이면 인터넷 연결 또는 API_URL 을 확인)
- 표시 페이지와 API 는 모두 공인 인증서(HTTPS)를 쓰므로 자체서명 인증서 문제가 없습니다.
  업무 서버를 사내에 따로 두지 않으므로 0.0.0.0 바인딩·HTTP 설정은 필요 없습니다.
- 접속 키를 다시 만들면 예전 주소는 검은 화면이 됩니다. 새 주소를 ViPlex 에 다시 등록하세요.
- 이미지는 업무포털이 화면 해상도에 맞춰 줄인 사진을 따로 만들어 저장합니다 (원본도 같은 폴더에 보관).
  앱스 스크립트에는 이미지 편집 기능이 없어, 줄이는 작업은 등록하는 사람의 브라우저에서 합니다.
- 화면에 꼭 맞는 이미지를 원하면 1152×160 / 2304×256 크기로 만든 이미지를 올리세요.
  두 화면의 비율(7.2:1, 9:1)이 달라 '둘 다' 로 올리면 한쪽에는 여백이 생길 수 있습니다.
- 표시 페이지는 4시간마다 조용히 새로고침합니다 (인터넷이 될 때만, 콘텐츠가 바뀌는 순간에).
- 표시 페이지 주소 끝에 &fit=0 을 붙이면 창 크기와 상관없이 해상도 그대로 그립니다.
  (기본은 페이지 크기가 해상도와 다르게 잡힐 때만 꽉 맞춤)
